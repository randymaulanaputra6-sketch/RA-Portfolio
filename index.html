About Me

Hi, I'm Randy Maulana and I'm a Game Developer!

Saya seorang solo developer asal indonesia dengan 1+ tahun pengalaman di bidang game development. Saya percaya bahwa game yang hebat tidak hanya diciptakan untuk dimainkan, tetapi juga untuk memberikan pengalaman yang berkesan - karena setiap detail, mekanik, dan interaksi memiliki peran dalam membangun sebuah dunia game.

Perjalanan saya di dunia game development dimulai dari rasa penasaran dan keinginan untuk menciptakan game sendiri. Saya belajar secara mandiri menggunakan Godot Engine dan GDScript, mulai dari perangkat sederhana hingga mengembangkan proyek 3D yang lebih kompleks. Melalui proyek seperti Tapak Adventure, Farmer Homer, dan Sate Life, saya terus mengasah kemampuan programming, game design, serta problem solving. Bagi saya, setiap proyek adalah kesempatan untuk belajar, bereksperimen, dan berkembang sebagai developer.
